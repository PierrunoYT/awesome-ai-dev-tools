# Contributing

Thanks for helping keep **Awesome AI Dev Tools** useful. Please read the scope before opening a pull request.

## Scope

This list covers AI tools for developers, grouped into sections:

- **AI Coding Tools**: coding agents and CLIs, AI-enhanced editors and IDEs, code completion and generation assistants, self-hosted and local-model coding tools, and codebase chat/search tools
- **Agent Orchestrators**: tools that run, coordinate, or supervise multiple AI coding agents (parallel runners, swarms, loop and task runners)
- **Agent Sandboxes**: sandboxes, runtimes, and isolation technologies for running agents and AI-generated code safely
- **Agent Memory**: memory layers, MCP memory servers, and memory benchmarks for AI agents
- **More AI Development Tools**: personal assistants, agent extensions (MCP servers, skills, plugins), app builders, code review/testing/security/docs tools, and other developer utilities

Generic AI products without a clear developer use case are out of scope.

## Requirements

- **Public and usable.** An official website, documentation page, or public repository, and people can use it today.
- **Not a duplicate.** Search the README first; each tool is listed once, in the section that fits best.
- **Neutral description.** Concise, factual, focused on concrete developer-facing capabilities. No marketing language.

## Format

Add entries in alphabetical order within their section:

```
**[Tool Name](https://example.com/)** - Brief description.
```

Entries under *More AI Development Tools* use `- [Tool Name](https://example.com/) - Brief description.`

## Submitting

Open a pull request that adds a single tool (or a small related batch) with enough context to explain why it belongs.
