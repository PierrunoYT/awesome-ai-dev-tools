## 🎯 About

This list focuses on AI tools that write, edit, and reason about code with you: coding agents, CLIs, AI-enhanced editors and IDEs, and code assistants. It is organized alphabetically for easy navigation.

### 🌟 What You'll Find Here:
- **Coding Agents & CLIs**: Terminal and cloud agents that plan, write, and run code
- **Code Editors & IDEs**: AI-enhanced editors with smart completions and integrated chat
- **Code Completion & Generation**: AI assistants that write code for you
- **Open-Source & Self-Hosted Options**: Local and bring-your-own-model coding tools
- **Codebase Understanding**: Chat, search, and explanation tools for working in large repositories

## 🤝 Contributing

Contributions are welcome. Please read the full [contributing guidelines](CONTRIBUTING.md) before opening a pull request. In short:

- Submit AI coding agents, CLIs, editors, IDEs, and code assistants. Orchestrators, MCP servers and skills, app builders, code review and testing tools, and personal assistants are out of scope for this list.
- Add new tools in alphabetical order using the existing format: `**[Tool Name](https://example.com/)** - Brief description.`
- Keep descriptions concise, neutral, and focused on concrete developer-facing capabilities.
- Include an official website, documentation page, or public repository link.
- Avoid duplicate entries, generic AI products without a clear developer use case, and purely promotional language.
- Open an issue or pull request with enough context to explain why the tool belongs in this list.
